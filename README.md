# Time Messenger

일정 시간이 지나면 메시지가 자동으로 삭제되는 실시간 메신저 애플리케이션입니다.

Spring Boot 기반으로 REST API와 WebSocket 서버를 구현했으며,
AWS EC2 Linux 환경에 서버를 배포하여 실제 클라이언트와 통신할 수 있도록 구성했습니다.

## 담당 역할

- Spring Boot 기반 백엔드 서버 개발
- REST API 구현
- WebSocket 기반 실시간 메시지 통신 구현
- AWS EC2 서버 배포
- Linux 서버 환경 및 네트워크 설정
- 서버 애플리케이션 서비스 등록

## Tech Stack

**Backend**
- Java 17
- Spring Boot
- Spring Data JPA
- Spring Security
- WebSocket

**Database**
- PostgreSQL
- Redis

**Cloud / Infra**
- AWS EC2
- Linux

**Build**
- Gradle
